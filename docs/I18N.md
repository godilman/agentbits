# Agentbits — Çoklu dil (i18n)

Arayüz **İngilizce (`en`)** ve **Türkçe (`tr`)** destekler. Dil, Ayarlar → Genel → **Dil** ya da kurulum ekranının ilk
adımından seçilir; varsayılan "Sistem" (işletim sisteminin dili; desteklenmiyorsa İngilizce). Ajanlara giden talimatlar
(prompt'lar) bilerek İngilizcedir; ajanlar kullanıcının yazdığı dilde cevap verir.

> **Kural (her geliştirmede):** Kullanıcının göreceği hiçbir metin koda yazılmaz. Her yeni metin **hem
> `en/` hem `tr/`** dosyasına aynı anahtarla eklenir; `npm run test:unit` (içinde `tests/i18n.test.ts`) geçmeden iş bitmiş
> sayılmaz.

## Dosyalar

| Yol | Ne |
|---|---|
| `src/shared/locales/<dil>/<bölüm>.json` | Çeviri dosyaları. Her dil bir klasör, her bölüm (namespace) bir JSON. **`en` referanstır.** |
| `src/shared/locales/index.ts` | Tüm dosyaları içe aktarır; `NAMESPACES` listesi, `resources` |
| `src/shared/i18n.ts` | `LANGUAGES`, `resolveLanguage`, `intlLocale`, `createI18n`, `I18nKey` tipi, `ts` (paylaşılan kod için) |
| `src/shared/i18n-types.d.ts` | Anahtarların tip denetimi: yanlış anahtar derlenmez |
| `src/main/i18n.ts` | Main süreç: `t`, `currentLanguage()`, `applyLanguageSetting()`, `allTranslations()` |
| `src/renderer/src/i18n.ts` | Renderer: `i18n`, `t`, `locale()`, `setLanguage()` |
| `tests/i18n.test.ts` | Denetim: diller arasında aynı anahtarlar (çoğullar her dilin kendi biçimleriyle) ve `{{yer tutucular}}`, boş değer yok, dizi yok, tüm dosyalar kayıtlı, kaynakta Türkçe harfli sabit metin yok |

Bölümler: `common` (ortak düğmeler, durumlar, zaman, durum çubuğu), `layout`, `onboarding`, `guide`, `org`, `agents`,
`connections`, `project`, `chat`, `office`, `terminal`, `tasks`, `reports`, `decisions`, `files`, `settings`,
`main` (main süreç hataları, bildirimleri, varsayılan adlar), `orchestrator` (sohbet/sistem mesajları, durum notları,
raporlar, sağlayıcı hataları), `templates` (şablon içerikleri), `demo` (Demo sağlayıcının ürettiği metinler),
`skills` (Skill'ler), `apps` (Uygulamalar / MCP).

## Kod içinde kullanım

```tsx
// React bileşeni — dil değişince yeniden çizilir
const { t } = useTranslation()
t('actions.save')                       // common bölümü: önek yok
t('settings:general.title')             // diğer bölümler: "bölüm:anahtar"
t('statusBar.agents', { count: 3 })     // çoğul: key_one / key_other
t('project:modal.deleteTitle', { name }) // yer tutucu: {{name}}
<Trans i18nKey="guide:intro" components={{ b: <b /> }} />  // metin içinde biçim

// Bileşen dışı (store, yardımcılar, tablo etiketleri)
import { t, locale } from '@/i18n'
const LABELS = { todo: { get label() { return t('taskColumns.todo') } } }   // getter: her okunuşta güncel dil
n.toLocaleString(locale())               // tarih / sayı biçimi asla 'tr-TR' sabit değil

// Main süreç
import { t } from '../i18n'
throw new Error(t('main:errors.projectNotFound'))

// src/shared/ (iki süreçte de çalışan kod)
import { ts } from './i18n'
```

Kurallar:
- Türkçe dosyadaki metin, arayüzde görünen metnin aynısıdır (Türkçe arayüzde İngilizce kalan "Chat", "Office", "To do"
  gibi sekme adları dahil).
- Çevrilmezler: ajanlara giden prompt'lar, ID'ler, `data-testid`, veritabanı enum değerleri, marka/ürün adları
  (Agentbits, Claude Code, Codex, PostgreSQL…), klavye tuşları, geliştiriciye yönelik `console.*` mesajları (İngilizce).
- Gerçekten Türkçe kalması gereken bir satır (ör. iki dilde kullanıcı girdisini yakalayan regex, "Türkçe" dil adı) satır
  sonuna `// i18n-ignore` alır.
- Veritabanına yazılan metinler (sistem mesajları, durum notları, denetim kayıtları, dosya notları) yazıldığı andaki
  dilde kalır. Dil değişince yalnızca **dokunulmamış varsayılan adlar** ("Organizasyon", "Varsayılan Proje",
  "Çekirdek Ekip", "Takım lideri") yeni dile çevrilir (`relabelDefaults`). Arayüzün tepki verdiği notlar ("Yazıyor…",
  "İnceleme · TA-3") her dilde tanınır (`lib/org.ts` → `isTypingNote`, `isReviewNote`).
- Dosya çıkarma iş parçacığı (`files/worker.ts`) i18next yüklemez: metinleri `workerData` ile alır.

## Denetim

```bash
npm run test:unit      # diğer birim testleriyle birlikte
npm run i18n:check     # yalnızca çeviriler, tüm bulguları listeler
```

Denetim, Türkçe harf (ç ğ ı ö ş ü) içeren sabit metinleri yakalar; "Sil", "Kaydet" gibi yalnızca ASCII harfli Türkçe
kelimeleri yakalayamaz — yeni ekranlarda tüm görünür metinleri gözle de kontrol edin.

## Yeni dil eklemek (topluluk) / Adding a language

1. Copy `src/shared/locales/en/` to `src/shared/locales/<code>/` (e.g. `de`) and translate the **values** only — keep keys,
   `{{placeholders}}` and `<b>…</b>` tags. For plural keys write exactly the forms your language uses
   (`Intl.PluralRules`: e.g. German `_one`/`_other`, Russian `_one`/`_few`/`_many`/`_other`) — the checker tells you which.
2. Import the files in `src/shared/locales/index.ts` (same pattern as `tr`) and add the language to `resources`.
3. Add `{ code: '<code>', name: '<native name>', intl: '<BCP 47>' }` to `LANGUAGES` in `src/shared/i18n.ts`.
4. Run `npm run i18n:check` and `npm run typecheck`, try it with `npm run dev` (Settings → General → Language), open a PR.
